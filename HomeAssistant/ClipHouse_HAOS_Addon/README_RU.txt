ClipHouse для Home Assistant OS (HAOS)
====================================

Что это
-------
Это упаковка ClipHouse 4.1 в локальное приложение Home Assistant (раньше
называлось add-on). Оно запускается автоматически вместе с Home Assistant,
хранит SQLite-базу в постоянном каталоге контейнера и синхронизирует историю,
избранное и удаления с Windows-компьютерами ClipHouse 4.1 в одной локальной сети.

Ограничение
-----------
У Home Assistant OS нет пользовательского рабочего стола и системного буфера
обмена. Поэтому HA-узел НЕ может автоматически читать Ctrl+C с Windows или
телефона. Он работает как круглосуточный веб-сервер и узел синхронизации.
Автозахват Ctrl+C остаётся включён на обычных Windows-компьютерах ClipHouse.
Текст, отправленный через веб-страницу HA, синхронизируется с остальными узлами.

Установка
---------
1. В Home Assistant OS установи официальное приложение Samba share (если ещё
   не установлено), задай логин и пароль, затем запусти его.
2. На Windows открой Проводник и введи:
      \\homeassistant\local_apps
   Если имя homeassistant не находится, используй IP Home Assistant:
      \\<IP-Home-Assistant>\local_apps
3. Распакуй этот архив на компьютере. Скопируй папку `cliphouse` из архива
   целиком в сетевую папку `local_apps`, чтобы получилось:
      local_apps\cliphouse\config.yaml
      local_apps\cliphouse\Dockerfile
      local_apps\cliphouse\run.sh
      local_apps\cliphouse\ClipHouse.py
   Не делай лишний уровень вложенности вида `local_apps\cliphouse\cliphouse\...`.
4. В веб-интерфейсе Home Assistant открой Settings / Настройки → Apps / Приложения
   → App store / Магазин приложений. В меню с тремя точками выбери Check for updates
   / Проверить обновления. При необходимости обнови страницу браузера.
5. В разделе Local apps найди «ClipHouse — общий буфер», нажми Install, дождись
   сборки и затем Start. Приложение настроено запускаться автоматически при старте HA.
6. Открой в браузере телефона/планшета/компьютера:
      http://<IP-Home-Assistant>:8787/
   IP можно посмотреть в сетевых настройках Home Assistant. Для удобной закладки
   желательно закрепить IP Home Assistant на роутере через DHCP reservation.

Сеть и синхронизация
--------------------
- ClipHouse HA использует TCP 8787 для сайта и UDP 8788 для автообнаружения.
- В конфигурации приложения включён host network, чтобы UDP broadcast обнаруживал
  Windows-узлы в той же локальной подсети.
- На каждом Windows-ПК должна быть та же версия протокола ClipHouse 4.1.
  Разреши программе входящие подключения в Windows Firewall для частной сети:
  TCP 8787 и UDP 8788 (в комплекте Windows-версии есть Allow_Firewall.bat).
- Компьютеры и HA должны быть в одной обычной локальной сети/подсети; гостевой Wi-Fi
  с изоляцией клиентов может блокировать обнаружение.

Хранение
--------
База находится в постоянном каталоге приложения:
    /data/ClipHouse/history.sqlite3
ID узла находится там же в node-id.txt. Перезапуск и обновление приложения сохраняют
эти данные. Не очищай данные приложения и сделай резервную копию Home Assistant,
чтобы защитить историю от потери устройства/накопителя.

Настройка ограничения длины текста доступна в интерфейсе конфигурации приложения:
max_text_chars, от 1 до 1 000 000 символов. Порты в этой сборке фиксированы: 8787/TCP
и 8788/UDP, они должны совпадать с настройками Windows-узлов.

Безопасность
------------
Текущий ClipHouse рассчитан на доверенную домашнюю сеть и не имеет отдельного входа
по паролю/PIN. Любое устройство с доступом к порту 8787 в этой сети потенциально может
читать, добавлять и удалять записи. Не настраивай проброс портов 8787/8788 в интернет.

Если приложение не показывается в списке Local apps, сначала проверь расположение
config.yaml и посмотри журнал Supervisor. Если оно не запускается, открой журнал
самого приложения в Home Assistant и пришли последние строки ошибки.


ClipHouse 4.1: все Windows-узлы и HA-приложение должны быть обновлены вместе (сетевой протокол 5). В этой версии добавлен двусторонний обмен PULL/PUSH, чтобы данные распространялись даже при асимметричном UDP-обнаружении. История SQLite и настройки нужно сохранить при обновлении.
