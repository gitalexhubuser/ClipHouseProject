# ClipHouse для Home Assistant OS

Подготовленная локальная сборка ClipHouse 4.1 как Home Assistant app. Подробнее см. `README_RU.txt`.

**Важно:** HA-узел хранит/раздаёт историю и синхронизируется с Windows-узлами, но сам системный буфер Windows он читать не может. Для авто-захвата `Ctrl+C` оставляй запущенные Windows-клиенты.


ClipHouse 4.1: все Windows-узлы и HA-приложение должны быть обновлены вместе (сетевой протокол 5). В этой версии добавлен двусторонний обмен PULL/PUSH, чтобы данные распространялись даже при асимметричном UDP-обнаружении. История SQLite и настройки нужно сохранить при обновлении.
