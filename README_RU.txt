ClipHouse — общий буфер обмена для домашней сети
================================================

ЧТО ЭТО
-------
Небольшой Python-сервер без сторонних Python-библиотек. На Windows он может
автоматически сохранять текст, скопированный в системный буфер, показывает
его на локальной веб-странице и синхронизирует историю с другими запущенными
экземплярами ClipHouse в локальной сети. Телефон использует обычный браузер.

БЫСТРЫЙ СТАРТ
-------------
1. Нужен Python 3.8 или новее. При установке включи Add python.exe to PATH.
2. Распакуй всю папку ClipHouseProject на каждый компьютер, где нужен общий буфер.
   Путь и буква диска на разных компьютерах могут отличаться.
3. Открой config.ini и при необходимости укажи настройки.
4. Запусти Start_ClipHouse.bat на каждом компьютере.
5. Разреши Windows Firewall доступ к частной сети, если Windows спросит.
6. Открой LAN-адрес из консоли на других устройствах. Адрес 127.0.0.1
   работает только на том устройстве, где ты его вводишь.

НАСТРОЙКИ config.ini
--------------------
[storage]
history_dir = %LOCALAPPDATA%\ClipHouse
max_history = 60

history_dir — каталог для файла history.json. Поддерживаются:
  D:\ClipHouseHistory
  %LOCALAPPDATA%\ClipHouse
  History                 (относительно папки с ClipHouse.py)

Укажи доступную для записи папку. C:\Windows\Temp может иметь особые права;
обычно удобнее D:\ClipHouseHistory или %LOCALAPPDATA%\ClipHouse.
Если ты переносишь history_dir после того, как уже накопилась история, вручную
скопируй старый history.json в новый каталог при выключенном ClipHouse.
Идентификатор узла хранится отдельно в %LOCALAPPDATA%\ClipHouse\node-id.txt,
поэтому смена каталога истории не создаёт для компьютера новый идентификатор.

max_history — сколько записей сохраняется на каждом узле. Допустимо от 1 до 500.
По умолчанию хранится только 60 последних записей, так что текущая версия сама
по себе не накапливает терабайты. Большие значения могут увеличить объём данных,
которые передаются на страницу; для многолетнего архива лучше отдельно сделать
постраничную историю на SQLite, а не включать бесконечное хранение в этой версии.

[clipboard]
auto_capture = true
max_text_chars = 100000

true — ClipHouse опрашивает системный Windows-буфер и добавляет новый текст в
общую историю. Это сохраняет всё текстовое содержимое, которое ты копируешь,
в том числе потенциально секреты. Не копируй пароли, если не хочешь сохранить их
и передать другим запущенным узлам.
false — системный буфер не отслеживается; текст добавляется через сайт вручную.
max_text_chars — максимальная длина одного текстового фрагмента.

[server]
http_port = 8787
discovery_port = 8788

Порты менять не нужно, если программа запускается без ошибок. После изменения
config.ini полностью перезапусти ClipHouse. На всех компьютерах, которые должны
общаться между собой, должны совпадать порты http_port и discovery_port.

КАК ПОЛЬЗОВАТЬСЯ
----------------
- В Windows нажми Ctrl+C в любой обычной программе: если auto_capture=true,
  текст попадёт в историю через небольшой интервал.
- На странице можно вручную отправить текст, скопировать последнюю запись или
  раскрыть историю и выбрать старую запись.
- На телефоне подключись к домашнему Wi-Fi и открой LAN-адрес компьютера.
- Если два узла включены, они автоматически обнаруживают друг друга через UDP
  broadcast и обмениваются записями истории.

ДВА АДРЕСА
----------
127.0.0.1 — loopback, адрес только текущего устройства. Он не подходит для
телефона или другого ПК.
192.168.x.x — LAN-IP сервера. Этот адрес используется с других устройств.

Чтобы иметь один легко запоминающийся адрес, закрепи в DHCP роутера постоянный
IP за одним компьютером, например 192.168.1.59. Затем добавь локальную DNS-запись
в Keenetic для имени clip.home.arpa, указывающую на этот IP. Если CLI поддерживает
команду ip host, пример:
  ip host clip.home.arpa 192.168.1.59
  system configuration save
После этого закладка может быть http://clip.home.arpa:8787/ . Имя указывает на
один конкретный ПК, поэтому для доступа по этой закладке он должен быть включён.
Домен .home.arpa предназначен стандартом для имён в домашней сети.

CTRL+C В КОНСОЛИ
----------------
Ctrl+C в окне, где работает сервер, останавливает Python-программу. Ctrl+C в
браузере, редакторе или другой программе работает обычно — копирует выделенный
текст. Не нужно нажимать Ctrl+C внутри консоли ClipHouse для копирования.

АВТОЗАПУСК
----------
После проверки можно запустить Enable_Autostart.bat. Он создаёт скрытый VBS-запуск
при входе пользователя в Windows. Для отключения запусти Disable_Autostart.bat.
Папку программы после настройки автозапуска не перемещай.

СЕТЬ И БЕЗОПАСНОСТЬ
-------------------
Если обнаружение или доступ с телефона не работают, запусти Allow_Firewall.bat
от имени администратора на нужных компьютерах. Правила рассчитаны на Private,
а не Public. Не делай проброс портов 8787/8788 из интернета на роутере.
Любой узел ClipHouse в доверенной локальной сети сможет получить общий текст.

ОГРАНИЧЕНИЯ ТЕКУЩЕЙ ВЕРСИИ
--------------------------
- Автоматический захват системного буфера доступен на Windows.
- iPhone не может незаметно читать системный буфер в фоне из браузера; на сайте
  можно вручную вставить или скопировать текст.
- При выключенном узле он получит новые записи после следующего запуска.
- Код использует только стандартную библиотеку Python; установка python-dotenv
  и других пакетов не требуется.
